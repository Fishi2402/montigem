# UMLP Rebranding - Namensvorschläge

Diese Tabelle dient zur Namensfindung für das UMLP Projekt. Der Name soll generell gut klingen und industrietauglich sein. Bitte in Nachfolgender Tabelle Namensvorschlag, euer Kürzel und eine optionale kurze Erklärung dazu abgeben. Die Vorschlagsliste ist wieder eröffnet. Gerne neue Ideen einstreuen.

| Namensvorschlag | Von | Kommentar / Erklärung | 
| - | - | - |
| SinoCore | CKi | Angespielt auf den Sinusknoten als zentraler Taktgeber: https://de.wikipedia.org/wiki/Sinusknoten (Grundidee: jedes angebotene Produkt stellt einen Teil des Körpers dar, um ein thematisch einheitliches Namensschema zu haben) | 
| Frisco | BR  |  Passend zu Acronio, Primo,  und kurz für San Francisco  |
| MoBaFlex | BR | Model Based Flexible Usage Tool |
| ACoGen | BR | Agile Code Generator |

| Fenix | MK | Abwandlung von Phoenix, der auch oft für Hoffnung und Zuversicht steht |
| MoRise | MK | Models Rising to the (SE) sky. Und alle reden darüber, ob es "Moraiß" oder "Morieß" ausgesprochen wird. |
| MoSys | NJ | **Mo**del-driven **Sy**stems Engineering Werkzeug. Anspielung auf Moses als Grundlage unserer Überzeugung MDSE in die Industrie zu bringen
| Cloudae | DS | Angelehnt an die hierarchische taxonomy der biologischen Lebensformen. Cloudae steht hier für die familie, Claudis wären deren genus, Cloudora die Ordnung der Cloud-Werkzeuge, und modelia die Klasse der Modellierungswerkzeuge. |
