A simple GUI-Wizard allowing WYSIWYG-like GUI Design.

| File             | -Description                                                                      |
|------------------|-----------------------------------------------------------------------------------|
| Wizard           | Page, setup, controlls, and GUI printer                                           |
| WizardData       | Contains the information on available GUI components. Modify this to add your own |
| WizardContainer  | Dynamic wrapper for inner components providing TemplateRefs                       |
| WizardModal      | Quick & Ugly moveable modal for input                                             |
| InspectorService | Eventmanager for control events                                                   |

Available components are described in the WizardData
