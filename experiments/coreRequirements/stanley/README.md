# Stanley

This project was generated with [Angular CLI](https://github.com/angular/angular-cli) version 12.2.0
using gradle plugin `com.github.node-gradle.node`.

## Gradle Build

Run `gradle build` to build the project together with the application.
Run `gradle :experiments:coreRequirements:stanley` to start the application.
The build will not finish, instead it will start a dev server.
Navigate to `http://localhost:4200/` to see the application.
Stop the running application by sending a termination signal (e.g. clicking `ctrl+c` in the console,
where the gradle process is running).
